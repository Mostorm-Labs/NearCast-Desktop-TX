# Windows x64 体积测量

测量对象是浏览器视频采集版本，基线提交 `2c09ff1`。三个阶段使用相同工具链（Rust 1.96.1、Tauri CLI 2.12.4）、Windows x64、逻辑版本 `0.1.0` / 本地 Build `2`、同一图标与 WebView2 downloadBootstrapper 策略，均实际生成 NSIS/MSI。没有捆绑完整 WebView2 Runtime，也没有在此任务中发布版本。

## 测量结果

1 MiB = 1,048,576 bytes。

| 产物 | 完整基线 | 删除旧模块、裁剪依赖并加入日志 | 加上速度优先编译优化 | 相对基线降幅 |
| --- | ---: | ---: | ---: | ---: |
| EXE | 15,068,672 B（14.371 MiB） | 14,624,768 B（13.947 MiB） | 13,582,848 B（12.954 MiB） | 9.86% |
| NSIS | 3,787,533 B（3.612 MiB） | 3,650,190 B（3.481 MiB） | 3,568,005 B（3.403 MiB） | 5.80% |
| MSI | 5,775,360 B（5.508 MiB） | 5,591,040 B（5.332 MiB） | 5,378,048 B（5.129 MiB） | 6.88% |

前端嵌入资源从约 303 KiB 降为 284 KiB。旧模块与平台 API 移除收益有限，主要原因是框架、网络、TLS、更新等仍是保留功能，且编译器本来就会删除部分不可达代码。EXE 大小与压缩后的安装包大小不是同一指标；WebView2 运行时、应用缓存和日志不包含在本表安装包字节数中。

## 保留能力

- 浏览器原始视频轨道直送 WebRTC，H.264/Opus 音视频、预览、停止、重选、配对/信令。
- Windows 原生 Touch 注入、输入状态清理、原生屏幕几何验证。
- AXTP 标准 framing、CRC、Touch 和全部当前定义的 Mouse 输入记录解码/状态校验。未实现的输入类型不协商、不注入。
- 原有局域网 mDNS 设备发现、指纹信任与显码请求。
- Mosapi 签名更新、后台检查下载、安装确认、缓存校验与更新清理。
- 新增有界日志和诊断导出：会话状态、启动/退出、每 30 秒性能计数，三个 1 MiB JSONL 轮转文件、最多五份本机导出，不保存配对码、SDP/ICE、窗口标题或音视频内容。
- macOS 构建保留现有能力及 `.app.tar.gz` 更新支持，本机不声明 macOS 产物体积/实机验证结果。

## 删除与编译设置

- 删除 WGC/D3D 视频回读、Canvas 上传适配、窗口枚举/缩略图、原生分享边框和触点覆盖层及对应 IPC/测试。
- 删除未接入 typed 通路的 Windows Mouse 注入后端，保留协议解码扩展点；macOS 原有 Mouse 通路未受影响。
- 缩减直接使用的 Win32 API features。Windows updater 禁用旧 ZIP 更新格式，继续接受签名 NSIS/MSI；macOS 保留归档解压。
- Release 使用 `opt-level=3`、ThinLTO、`codegen-units=1`、`strip=symbols`。没有采用 `opt-level=s/z`、UPX 或关闭核心功能；没有把 panic 改成 abort，避免改变现有清理/失败语义。

## 验证与限制

- 162 项 JavaScript 测试通过，包含独立协议语料的全部当前 input 类型；测试数下降来自删除已移除模块的测试。
- Rust 33 项通过、3 项明确忽略；包括日志轮转/字段限制和更新签名缓存校验。
- `cargo check --locked`、`git diff --check` 通过。
- Edge 真实 SDP/ICE/DTLS/SCTP/RTP 集成通过：原视频轨道、Opus 有能量、Touch、窗口/多屏拒绝输入但媒体继续、sender 复用、诊断导出 UI。
- 软件更新弹窗回归通过。
- 优化版真实 NSIS/MSI 及其 updater 签名生成通过，EXE 启动响应正常，日志文件实际创建并写入启动/会话记录。
- 本轮未替换用户安装、未发布更新，压缩包安装与真实跨版本升级仍沿用发布验收要求。合成采集/PCM 测试不能替代现场流畅度、听感、物理触控与 macOS 实机测试。
