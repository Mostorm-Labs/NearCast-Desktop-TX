# NearHub Cast TX 配置与默认值清单

适用于基于提交 `18a739a` 的当前工作区，整理日期为 2026 年 11 月 19 日。涵盖 Windows 和 macOS 发送端，不包含 RX 的配置。当前 Windows 本地 Release 构建为 `0.2.0.43`，已包含高级画质控件默认隐藏及默认参数调整。

下面的默认值指首次运行、没有已保存偏好时的源码默认值。正常升级继续沿用本机已保存的选择；本清单不读取或代表某台电脑当前保存的配置。系统权限和实际采集、编码结果需由运行时确认。

## 设置界面可修改的配置

这 8 项均位于 **Casting Settings → General**，保存在本机 WebView 的 `localStorage`，键名为 `nearhub-cast-settings-v1`。其中分辨率、码率模式和码率作为高级画质配置默认隐藏，其余 5 项正常显示。

在设置页顶部“Cast Settings／投屏设置”标题连续点击 **8 次**显示高级画质配置，再点击 **8 次**隐藏。显隐状态只在本次运行保留，重新启动或重新加载后恢复隐藏；返回主页会清除未完成的点击计数。隐藏不重置参数，已保存的高级选择仍会生效。

| 配置项 | 源码默认值 | 可选值 | 生效时机与说明 |
| --- | --- | --- | --- |
| 外观 `theme` | 跟随系统 `system` | 跟随系统、深色 `dark`、浅色 `light` | 即时生效；跟随系统时响应系统外观变化，原生窗口和选择器同步主题偏好。 |
| 显示语言 `language` | 跟随系统 `system` | 跟随系统、中文 `zh`、English `en`、日本語 `ja`、Deutsch `de` | 即时生效；跟随系统时按系统语言列表匹配，未匹配到支持的语言则使用英语。 |
| 视频分辨率 `video.resolution` | **1920 × 1080** | Auto（来源尺寸）、1280 × 720、1920 × 1080、2560 × 1440、3840 × 2160 | 默认隐藏。下次开始分享时生效；选定尺寸作为浏览器的理想输出约束，实际尺寸由来源与浏览器决定。 |
| 码率模式 `video.bitrateMode` | **动态自适应 `dynamic`** | 固定目标 `fixed`、动态自适应 `dynamic` | 默认隐藏。下次开始分享时生效；固定模式使用 `maintain-resolution`，动态模式使用 `balanced` 降级策略。已有保存的模式不会因默认值改变而被覆盖。 |
| 视频码率 `video.bitrateKbps` | **8000 Kbps（8 Mbps）** | 2、4、8、12、20 Mbps | 默认隐藏。下次开始分享时生效；两种模式均将选值设置为 WebRTC 的 `maxBitrate` 上限，实际码率可以低于该值。 |
| 分享系统声音 `systemAudio` | **开启 `true`** | 开启、关闭 | 下次开始分享时生效；不采集麦克风。投屏卡片提供同一偏好的快捷开关，分享进行时该快捷开关不可修改；可在 General 调整下次分享的偏好。macOS 未确认相关权限时会关闭此偏好。 |
| 局域网投屏 `localSignaling` | **开启 `true`** | 开启：仅使用所选 RX 的本地信令；关闭：使用云端协商 | 下次连接生效；本地不可用时不会自动回退云端。修改后需取得对应连接方式的配对码，手工云端输码需先关闭此项。 |
| 允许反控 `inputEnabled` | **关闭 `false`** | 开启、关闭 | 即时生效并保存。需同时满足整屏来源、本机输入能力、RX 能力与总开关、反控会话及必要系统权限。窗口投屏时保留偏好但禁用开关，不能进行反控。 |

**固定目标码率并非恒定码率。** 当前两种模式都设置码率上限，没有通过界面配置严格 CBR 或最低码率；浏览器仍可根据网络、编码器和来源内容降低实际流量。展开高级配置后，动态模式仍可以选择 20 Mbps，但不保证一定达到该码率，也不能解决来源采集帧率不足。当前默认使用动态模式、8 Mbps 上限及 1080p 分辨率。

投屏卡片中的反控快捷开关在 RX 明确不支持反控、总开关关闭或状态未就绪时禁用；这些状态不等于本机保存的反控偏好被改写。

## 每次连接或本次运行可调整的项目

这些项目不属于上面的持久偏好。

| 项目 | 初始状态 | 修改入口与行为 |
| --- | --- | --- |
| 接收设备 | 未选择 | 首页设备列表选择；断开后返回列表并清除本次选择。 |
| 配对码 | 空 | 输入所选 RX 显示的 4 位字母或数字；小写自动转为大写。配对码不会写入偏好或诊断日志。 |
| 采集来源 | 未开始采集、未选择屏幕或窗口 | 连接后点击开始分享，使用系统选择器选择来源；停止后可重新选择。Windows 提示优先显示“整个屏幕”，仍可选择窗口。 |
| Session 采集预览 | 折叠 | 投屏页底部展开或收起；断开回到空闲状态时折叠。预览播放静音，收起预览不停止投屏。 |
| 主窗口大小与位置 | 默认 **946 × 692 逻辑像素** | 可拖动、缩放、最大化和还原；Windows 最小尺寸 640 × 480。当前没有保存窗口几何状态的插件。 |
| 反馈邮箱 | 空，必填 | Settings → Feedback；最多 254 长度，提交时还需通过邮箱校验。不是本机长期偏好。 |
| 反馈问题描述 | 空，必填 | Settings → Feedback；最多 4000 字，提交前去除首尾空白。 |
| 同意上传反馈与诊断包 | **默认勾选** | Feedback 底部复选框；只有用户主动提交才上传。提交成功后取消勾选，本次页面内需重新勾选才能再次提交。 |
| 更新安装选择 | 自动检查和下载，安装等待用户操作 | Settings → Check for Updates；可手动检查、关闭提示或选择安装。当前没有自动检查、自动下载的开关。 |

## 由操作系统管理的权限

Settings → Permissions 提供权限状态和系统设置入口。打开设置页面不等于已授权，权限也不由 `nearhub-cast-settings-v1` 控制。

| 权限 | 软件默认值 | 平台行为 |
| --- | --- | --- |
| 本地网络 | 无固定开启或关闭默认值，以系统状态为准 | macOS 用于发现设备，点击入口进入系统设置；Windows 由系统网络与防火墙管理。局域网投屏开关控制连接方式，不是 OS 权限开关。 |
| 录屏与系统录音 | 无固定授权默认值 | macOS 原生系统声音依赖相应授权；画面是否需要长期录屏授权由运行时能力决定，也可能使用每次会话的系统选屏授权。Windows 在系统选择器中授权分享来源。 |
| 辅助功能 | 无固定授权默认值 | macOS 反控依赖此权限；未确认授权时不启用反控。Windows 不使用 macOS 辅助功能权限。 |

macOS 已保存的系统声音与反控开关在启动时仍须重新确认权限。缺少或无法确认权限时，实际生效状态可与表中的初始偏好不同；不会仅凭过去保存的 `true` 越过系统检查。

## 已隐藏的输入转换与手势配置

当前普通界面隐藏 Advanced Input Settings。启动时固定应用 `DEFAULT_OUTPUT_POLICY`：**Touch → 原生 Touch，Mouse → 原生 Mouse**。旧偏好中的自定义转换不会在启动时恢复。不支持原生 Touch 的 macOS 不会因此自动将 Touch 转为 Mouse。

下表是内部兼容模块接受的配置，需要开发入口显式应用；不能作为普通用户当前可见的设置。转换策略改变时需释放已有输入并重新协商。

| 内部配置 | 模块默认值 | 支持值或范围 |
| --- | --- | --- |
| `policy.touch` | `native` | `native`、`mouse-drag`（点击拖拽）、`mouse-scroll`（轻点点击／滑动滚动）、`mouse-gestures`（组合手势）、`disabled`；可用项受本机能力限制。 |
| `policy.mouse` | `native` | `native`、`touch`（左键单点触控）、`disabled`；转换为 Touch 需本机支持。 |
| `policy.gestures.holdMs` | **300 ms** | 模块校验范围 150–2000 ms；保留的隐藏编辑器范围 150–1000 ms，步长 50 ms。 |
| `policy.gestures.rightClick` | `hold`（单指长按后松手） | `hold`、`two-finger`（双指轻点）。 |
| `policy.gestures.rightHoldMs` | **700 ms** | 模块范围 150–3000 ms，且不得小于拖拽等待；隐藏编辑器上限 2000 ms，步长 50 ms，最小值随拖拽等待调整。 |
| `policy.gestures.moveThreshold` | **6 个本机坐标单位** | 模块范围 3–30；隐藏编辑器没有此项控件。 |
| `policy.gestures.twoFingerTapMs` | **350 ms** | 模块范围 150–600 ms；隐藏编辑器没有此项控件。 |
| `policy.gestures.pinchAction` | `disabled`（不输出缩放） | `disabled`、`browser-zoom`（需相应能力）、`ctrl-wheel`（需 Ctrl＋滚轮能力）。 |
| `policy.gestures.pinchStep` | **0.12** | 模块范围 0.05–0.4，为缩放比例的对数步长；隐藏编辑器没有此项控件。 |
| `policy.gestures.feedback` | **开启 `true`** | 开启、关闭；仅在组合手势策略中有意义，Windows 尚无桌面光圈实现。 |

手势表中的默认值仅在组合手势模块被显式启用时有意义。例如默认 `feedback=true` 不表示当前原生输入策略会显示光圈。隐藏编辑器在 macOS 有网页缩放能力且未保存选择时可能预选网页缩放，但启动的实际默认策略仍是原生输入，手势模块自身的默认 `pinchAction` 仍为 `disabled`。

**TX 当前没有可配置的滚动速度倍数。** RX 的手势滚动速度由接收端管理，不能列为 TX 默认配置。

## 当前固定的采集与运行参数

这些值影响行为，但普通界面没有调整入口。修改它们需要改源码或打包配置，并重新编译。

| 参数 | 当前值 | 来源与说明 |
| --- | --- | --- |
| 视频采集与发送帧率上限 | **30 fps** | `VIDEO_FRAME_RATE`；初次选屏及后续约束均为 `ideal:30, max:30`，sender 的 `maxFramerate=30`。实际帧率不保证达到 30。 |
| 视频采集后端 | 浏览器 `getDisplayMedia` | 使用浏览器原始视频轨道交给 WebRTC，没有可切换的原生 WGC 视频后端。 |
| Windows 来源选择提示 | `displaySurface: 'monitor'` | 提示优先显示整个屏幕，由运行时决定是否采用；不限制窗口选项，不自动选定物理屏幕。macOS 不附加此提示。 |
| 视频细节提示 | `contentHint='detail'` | 编码器优先保留文字和细节。 |
| 视频与音频编码 | **H.264 / Opus** | 没有编解码器选择控件；不暴露强制硬编／软编开关。 |
| 独立系统音频 PCM | **48 kHz、双声道、Float32** | Windows WASAPI；macOS 优先使用系统选择器音轨，缺少时使用原生系统音频。没有应用内音量或麦克风选择控件。 |
| 分享后自动最小化 | **不执行** | 分享、停止与断开保留当前窗口状态，无自动最小化开关；用户可手动最小化。 |
| 启动主页面 | **设备选择列表** | macOS 必需权限未就绪时先显示授权引导；是否曾完成引导不代替实际权限检查。 |
| 设备列表高度 | **固定四行空间** | 超过四个设备时在列表内滚动，无列表密度或行数设置。 |
| Windows 整屏绑定校准 | 识别最多 **5 秒** | 通过短暂四角标记识别所选物理屏幕；视频成功不代表反控绑定一定成功。 |
| 本地信令连接超时 | **7 秒** | IPC WebSocket 适配器固定值，无用户超时设置。 |
| 请求 RX 显示配对码超时 | **6 秒** | 客户端默认值，无界面入口。 |
| 接收端请求反控的同意时限 | 默认 **8 秒** | 具体请求可传入时限；到期拒绝，不视为用户同意。 |
| 首次后台更新检查 | 更新 UI 挂载后约 **2.5 秒** | 首次检查发现更新可提示；自动下载后由用户选择安装。 |
| 更新检查周期 | 成功后 **4 小时** | 失败时从 1 分钟开始指数退避，最高 30 分钟。无界面周期设置。 |
| 诊断常规采样 | **30 秒** | 投屏期间有新媒体统计时，媒体记录按至少 5 秒间隔补充；会话和输入事件另有记录。 |
| Feedback 请求超时 | 总时限 **90 秒**，连接 **10 秒** | 同时只允许一次提交，诊断 ZIP 最大 4 MiB；没有用户调整入口。 |

## 服务地址和构建配置

普通用户不需要修改这些项。服务地址和更新产品标识属于当前后台契约，不能仅因改名而变更。

| 项目 | 当前默认值或当前值 | 修改方式与边界 |
| --- | --- | --- |
| 云端信令地址 | `wss://cast.nearhub.us` | 默认常量；WebView 页面支持 `?ws=...` 调试覆盖，但没有软件设置入口，也不是命令行参数。只在云端路径使用，本地模式连接所选 RX。 |
| 本地信令地址 | 无固定 IP；由所选 RX 的当前发现与运行实例决定 | 选择设备后通过原生桥接解析与校验，UI 不接受任意本地 URL；本地模式显式使用 `iceServers: []`，不自动回退云端。 |
| 更新渠道 `NEARCAST_UPDATE_CHANNEL` | **`release`** | 构建时可选 `release`、`beta`、`alpha`；写入编译产物，应用内无法切换。 |
| 更新查询地址 | `https://mosapi.auditoryworks.co/v1/updates/product/<slug>` | Rust 固定；Windows slug=`nearcast-tx-windows`，macOS slug=`nearcast-tx-macos`，不能跨平台查询。 |
| Feedback 服务 | `https://mosapi.auditoryworks.co/v1` | Rust 固定；Windows application ID=39，macOS=40。与更新 product ID 分开。 |
| 逻辑版本与构建计数 | 当前 `logicalVersion=0.2.0`，`build=43` | `build-version.json` 为权威；应用构建自动递增并写回 Build，检查与测试不递增，不回退或复用已分配编号。 |
| 主窗口初始尺寸 | `946 × 692` | `src-tauri/tauri.conf.json`；Windows overlay 同步尺寸并设置最小 `640 × 480`。用户拖动大小无需重新编译。 |

## 存储和默认配置对象

常规设置仅保存在本机，不通过 RX 或云端同步。以下为未保存设置时的偏好对象；隐藏手势子对象未显式添加时由模块补默认值，实际启动始终应用原生输入策略。

```json
{
  "video": {
    "resolution": "1920x1080",
    "bitrateMode": "dynamic",
    "bitrateKbps": 8000
  },
  "language": "system",
  "theme": "system",
  "localSignaling": true,
  "systemAudio": true,
  "inputEnabled": false,
  "policy": {
    "touch": "native",
    "mouse": "native"
  }
}
```

设置键为 `nearhub-cast-settings-v1`。损坏或读取失败的设置回退到默认值；不受支持的视频档位或无效输入策略也会触发整体默认回退，语言和主题的未知值各自回退为跟随系统。升级沿用已保存偏好，Windows 的旧页面设置迁移也保留此键。

外观、语言、画质、码率、系统声音、局域网投屏和反控偏好在修改时保存，不必等到退出。正常关闭后再次打开会读取上次保存的值；配对码、当前接收端选择、采集来源与高级配置显隐状态不会恢复。macOS 系统权限检查及当前来源与 RX 能力仍约束功能的实际可用状态。

自动建立的设备公钥信任保存在应用数据目录 `trusted-devices-v1.json`，不属于用户可编辑的普通偏好。macOS 授权引导完成标记单独使用 `nearhub-cast-macos-permissions-onboarding-v1`，该标记不授予 OS 权限。
