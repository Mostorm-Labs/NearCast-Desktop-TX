# NearHub Cast 0.2.0 alpha

- 与 RX 的 AXTP 开发合同同步，支持标准反控输入策略和总开关控制的配套联调。
- 默认采集帧率为 30 fps，保留既有码率；分享后保持发送端窗口可见。
- 支持优先局域网的本地信令流程及反控滚动诊断。
- 构建次数由文件递增，同批 Windows / macOS 共用编号。

此 alpha 使用未正式发布的 AXTP 合同 0.18.0-dev.0082a3428b1e，
反控需要配套更新 RX；旧合同指纹会被拒绝，普通投屏不受此门禁影响。
macOS 包未配置 Developer ID 签名和公证，需要按测试包方式安装；
本次未在真实 Mac 上验收采集与辅助功能权限。
