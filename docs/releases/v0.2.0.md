# NearHub Cast 0.2.0

- 提供 Windows x64、macOS Intel 和 Apple Silicon 安装产物，同批产物使用相同的四段版本号。
- 更新设备列表、连接与投屏界面，支持深色、浅色和跟随系统外观，以及多语言设置。
- macOS 在发现设备、分享系统声音和开启反控时检查相应权限，提供系统设置快捷入口；取消选屏不再误报为必须开启录屏权限。
- 支持分享系统声音，不采集麦克风。Windows 使用 WASAPI；macOS 14.2 及以上使用 Core Audio Tap，修复启用声音后再次选屏等待超时的问题。
- 支持整屏反控和按平台能力进行输入转换；macOS 支持鼠标及触控式滚动，Windows 支持鼠标和触控。窗口投屏仅分享画面。
- 新用户默认采用 1080p、30 fps、动态自适应码率和 8 Mbps 上限。高级画质配置默认隐藏，连续点击设置页标题八次可显示；升级保留已保存的配置。
- 正式更新包及平台版本清单均提供签名和 SHA-256 校验；macOS 发布流程要求 Developer ID 签名、Apple 公证和 Gatekeeper 检查。

系统要求：Windows 10/11；macOS 13 或以上。macOS 分别提供 Intel 与 Apple Silicon 包，请选择匹配架构；不支持 macOS 10.x。macOS 13–14.1 保留 ScreenCaptureKit 音频兼容后端，该范围的连续有声投屏尚未完成实机验证；需要分享系统声音时建议使用 macOS 14.2 或以上。

反控需要接收端使用匹配的 AXTP typed-input 合同 `0.18.0-dev.feac6fa2a4b9`；旧合同指纹会被拒绝，普通投屏不受此门禁影响。macOS 反控需要辅助功能授权，当前仅支持分享整个主屏幕。
